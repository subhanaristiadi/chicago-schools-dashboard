Key Findings

Plain-English takeaways computed live from the current data scope.

    Limitations — read before over-interpreting

    • Single-year snapshot. 2011–2012 report cards only; year-to-year swings and one-time events can dominate differences.
    • Correlation ≠ causation. A safe climate and strong instruction may share hidden drivers (funding, leadership, neighborhood); we do not claim safety causes better instruction.
    • Missing data, not imputed. Scores are null wherever the source is blank or “NDA”; each analysis uses only complete cases and reports its n. No values were filled in.
    • Small middle-school sample. Only 11 middle schools report card data, so any MS-only statistic is fragile.
    • Metric scope. ISAT value-add mostly covers ES/MS, while graduation/ACT/college-enrollment cover HS; grouped comparisons always state which population is included.
    Source: City of Chicago Data Portal — Chicago Public Schools – Progress Report Cards (2011–2012). Scores are percentile-style (1–99). Percentages “NDA” / “N/A” / blanks are treated as missing and excluded per analysis.
